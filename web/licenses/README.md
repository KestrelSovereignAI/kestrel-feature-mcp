These are unmodified notices for code already embedded in the official
`@modelcontextprotocol/client` distribution. `vendor-notices.json` records each
original version, npm tarball integrity and license hash. These records identify
the embedded source; they do not constrain the runtime dependency resolver.

The build reads dependency source maps, requires notices for every embedded
package it discovers, verifies the original notice bytes and includes them in
the packaged `THIRD_PARTY_NOTICES.txt`. New embedded packages or versions require
reviewed attribution before a build can pass. The npm dependencies are unmodified.

The `@cfworker/json-schema` npm archive omits its license file. Its notice is
copied from `LICENSE.md` at the archive metadata's exact upstream `gitHead`, as
recorded in `vendor-notices.json`.
